# كلود يدق عليك 📞

أداة MCP اسمها `call_me` تخلّي Claude يتصل على تطبيق Linphone في جوالك.
اسم المتصل اللي يطلع لك = الرسالة (مثل: "خلصت المهمة").

## 1) سوّ حسابين Linphone (مجاناً من subscribe.linphone.org)
- **حساب لجوالك** (مثلاً `raghad`): سجّل فيه داخل تطبيق Linphone.
- **حساب للبوت** (مثلاً `raghad-bot`): هذا اللي يتصل منه Claude.

## 2) على جهازك (كمبيوتر فيه Claude Code و Python 3)
```bash
# الحسابات مضبوطة: البوت ren7676 يتصل على sh6767
export SIP_PASSWORD='كلمة_مرور_ren7676'
python3 sip_call.py "تجربة"          # لازم يرن جوالك
```

## 3) شغّل Claude Code من هذا المجلد
ملف `.mcp.json` يضيف الأداة تلقائياً. بعدها قل له مثلاً:
"لما تخلص، دق علي".

## تنبيه احتياطي (ntfy)
لو فشلت المكالمة (مثل سيرفرات Claude السحابية)، يرسل لك إشعار عاجل بدلها:
1. نزّل تطبيق **ntfy** (Android / iPhone).
2. اشترك في الموضوع: `raghad-claude-11a2604d`
3. خلاص، أي تنبيه من Claude يوصلك حتى لو ما زبطت المكالمة.

اسم الموضوع في `.mcp.json` (`NTFY_TOPIC`)، وتقدر تغيّره لأي اسم صعب التخمين.

## ملاحظات
- يتصل عبر TLS على المنفذ 5061 (لو ما زبط جرّب `export SIP_TRANSPORT=tcp`).
- لو رديت، يقفل بعد ثواني (ما فيه صوت، الهدف التنبيه).
- سيرفرات Claude السحابية ما تقدر توصل لـ Linphone، فلازم يشتغل على جهازك.
